# TiO2-arsenic-adsorption-VASP
VASP input files and post-processing files for arsenic species (oxides-acids) adsorption on TiO2(101)

Computational details:
- VASP version: 5.4
- Exchange-correlation: PBE
- Plane-wave cutoff: 400 eV
- Surface models: anatase (101)
- Van der Waals: Grimme
- VASPsolv

Contents:
- inputs/: INCAR files (2 examples)
- structures/: optimized geometries (CONTCAR)
